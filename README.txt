Publish free:
1. Create/sign in to a GitHub account.
2. Create a new public repository (for example, abbatyusa-venture).
3. Upload index.html.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the site; the published address will appear in Settings > Pages.
